This repo contains an archive of the projects I made during the pandemic on Khan Academy. It contains two files, UI - which contains mock up designs for websites and a game - and Natural Simulations - which contain some of the projects I made as part of the
Nat Simulation course on Khan Academy. Below is a brief description of each project.

# UI
- Dodge.io: a game where the user plays as a block to dodge squares from the sky. I created a ranking system, boosts, sound effects and character customization for the game.
- SafeCoin: a mockup for a website that helps children maintain a wallet of money to learn financial literacy, made part of a computer science project in Grade 7.
- Geography: a mockup for a website that teaches users geography facts, made for my little brother.
- Newspaper: a mockup for a school newspaper website, from my unrealized dream to have free press in school. 
- Story-writing: a mockup for a website that helps people perform creative tasks in a dedicated user interface. I only ended up creating the "writer" page.
- Chat: a mockup for a chatting app dedicated for young children with built-in parental controls. 

# Natural Simulations
- Creature: Khan Academy's project to design a creature with autonomous movement. My first experience with Vectors. I was quite proud of the OOP I used for this.
- Noise: Khan Academy's project to help learn Gaussian noise. 
- Random: Khan Academy's project to use randomness to create a paint splatter.
